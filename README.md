# Future-Interns-Cyber-Security-Task-2
An operational cybersecurity defense blueprint and threat analysis portfolio simulating a Tier-1 SOC Analyst workflow. Features real-world phishing deconstruction, lookalike domain tracking, and a human-centric corporate awareness framework.

## 📌 Project Overview
This repository functions as a technical portfolio piece replicating the defensive workflows of a Tier-1 SOC (Security Operations Center) Analyst. It processes raw infrastructure indicators from active phishing samples, maps exploit structures, and presents polished operational user-awareness briefs to mitigate workforce exploitation.

## 🛠️ Security Analysis Tools Referenced
* **Google Admin Toolbox MessageHeader:** Inbound mail routing tracking and server hopping analytics.
* **MXToolbox Headers Engine:** Advanced verification of cryptographic signing mechanisms (SPF, DKIM, DMARC alignment status).
* **URL Defang Formatters:** Transforming malicious hyperlink tracking tokens into secure text references (`[]`).
